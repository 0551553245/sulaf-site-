# Reference images

Put your reference images in this folder: screenshots of websites you like, Pinterest designs, competitor pages, packaging, and photos with the mood you want.

Tip: name each image by what you like about it, for example:
- `hero-layout-like-this.png`
- `colors-and-mood.jpg`
- `scroll-animation-idea.png`
- `flavor-cards-style.png`

These images decide the look of the site.
